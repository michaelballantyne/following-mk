# 8x8 Latin square: the win scales combinatorially

Follow-up to `claude/2026-07-12-173259-latin-square-existence-proof.md`,
which predicted "bigger boards would presumably widen the gap
arbitrarily." Measured (subagent extension of
`experiments/latin-square.scm`; 26 givens / 38 empty, cyclic solution,
uniqueness + naked-single-solvability verified exhaustively offline):

| instance | unify(main) A→B | ratio | conde(main) ratio | wall ratio |
|---|---|---:|---:|---:|
| 6x6 prop | 92,736 → 552 | 168× | 53× | 14.5× |
| **8x8 prop** | **14,309,304 → 1,290** | **11,092×** | **3,355×** | **934×** |

Each metric's *ratio* grew ~65× from 6x6 to 8x8: the baseline blows up
combinatorially with board size while the follower's cost stays
essentially linear in the number of empty cells (`conde (main)` = 38 =
exactly the non-given cells; the whole board again solved in a single
install-time propagation firing; suspend cutoffs still zero).

Nothing subtle to interpret — this is the expected behavior of unit
propagation vs. backtracking, now measured in *this* codebase with
*this* follower implementation and the fair work metric. The research
goal's "orders-of-magnitude in some context" is settled with headroom:
the gap is unbounded in N, and the wall-clock win (934×, overhead
included) removes any "but the overhead" asterisk in the FD regime.
